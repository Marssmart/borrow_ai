Edit memories

Design guide for editing a saved memory on Android. Editing the title and summary is shipped. The transcript and categories are still mockups. Full spec: Edit memories design.

Shipped The Edit button, the full-screen editor for title and summary, their limits, the discard prompt, saving, and the failure and deleted states are shipped on Android. Sections marked Mockup are not built yet: the transcript and category parts of the editor. Android only The layout uses Material 3 components. iOS is not designed here.

Shipped · 1 · Entry and editor

Edit button and full-screen editor Shipped Original transcript: Mockup

Edit opens a full-screen page inside the Memories tab. The dock stays hidden, and the pager stays locked, as it is in the detail view. Cancel asks before discarding changes.

Shipped · 2 · Validation

Field rules and messages Title, summary, transcript, and categories: Shipped

Save stays disabled until a field is valid and something has changed. Each message sits under its field and is read by TalkBack when focus reaches it.

Shipped · 3 · Transcript and AI

Transcript field and regeneration banner Shipped Original transcript and Edited tag: Mockup

While the transcript is still being made, its field is read-only. After a transcript edit, the app does not regenerate anything by itself. A banner offers each action, and a dialog asks before replacing text the user wrote.

Shipped · 4 · Cancel and save

Discard prompt, saving, and failure Shipped

Cancel with changes asks first, and Keep editing is the default. A save that fails keeps every change on screen and offers Retry.
