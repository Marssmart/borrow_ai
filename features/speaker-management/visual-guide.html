End-to-end assignment and correction

Each mutation targets one occurrence, is committed locally, and leaves the original memory and recording intact.

Open the occurrenceFrom a memory row chip or its speaker card.
Listen, if availablePlay the sample from the source recording.
Choose or createSearch the library or create-and-assign a name.
Commit the linkOnly the selected occurrence changes; views refresh from stored state.
Review laterRecent matches in speaker detail return to the exact memory card.
Privacy distinction: Turning recognition off pauses analysis and keeps the library. Withdrawing consent stops analysis and deletes speaker data. Deleting one identity removes that identity's links and voiceprints, not the underlying memories or audio.
